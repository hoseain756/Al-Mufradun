# المفردون — فيلم ترويجي

مشروع Remotion مدته ٤٢ ثانية، بنسختين متطابقتين في التكوين: أفقية ١٦:٩ وعمودية ٩:١٦، وكلاهما مضبوط على ٦٠ إطاراً في الثانية.

## المعاينة

```powershell
npm run dev
```

اختر `AlMufradun-Preview` للمعاينة السريعة، أو إحدى تركيبتي 4K للتحقق من مناطق الأمان.

## التصدير

```powershell
.\render-deliverables.ps1
```

ينشئ السكربت ملفين 4K داخل `out`:

- `almufradun-promo-4k-60fps.mp4`
- `almufradun-promo-vertical-4k-60fps.mp4`

## ملاحظات فنية

- الخطوط المستخدمة هي ملفات التطبيق الأصلية: TheYearofHandicrafts، alnasakh، وUthmanicHafs.
- الخلفية الصوتية أصلية بلا غناء، مع نقرات واجهة خفيفة وفيد إلى الصمت في الإغلاق.
- التكوين مخرَج SDR/Rec.709. لإصدار HDR حقيقي، يجب تمرير الماستر إلى تدرّج لوني HDR (PQ أو HLG)؛ لا يصح وسم محتوى CSS بنطاق ألوان SDR كـ HDR بلا تدرّج فعلي.
